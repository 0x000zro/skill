# 🚀 CDP Learning App — Complete Architecture & Setup Guide

This project is a production-grade, offline-first educational Android application designed for **CTET & UPTET Child Development & Pedagogy (CDP)** candidates. It is powered by a **GitHub repository acting as a Headless CMS**.

---

## 🏗️ Architectural Overview

```
                      +---------------------------------------+
                      |       Remote GitHub Repository        |
                      |   (study/, revision/, practice/, test/)
                      +-------------------+-------------------+
                                          |
                              GitHub Action Push Trigger
                                          |
                      +-------------------v-------------------+
                      |      Auto-Generated manifest.json     |
                      |     (via generate_manifest.py script) |
                      +-------------------+-------------------+
                                          |
                                HTTP GET (Raw GitHub API)
                                          |
                      +-------------------v-------------------+
                      |         Android Client App            |
                      +-------------------+-------------------+
                                          |
                          Offline-First Repository Layer
                                          |
                 +------------------------+------------------------+
                 |                                                 |
+----------------v-----------------+             +-----------------v----------------+
|         Network (Online)         |             |       Local Cache (Offline)      |
| Retrofit + OkHttp Cache Intercept|             |   Room Database (AppDatabase)    |
+----------------------------------+             +----------------------------------+
                 |                                                 |
                 +------------------------+------------------------+
                                          |
                                    Flow<Resource<T>>
                                          |
                 +------------------------v------------------------+
                 |            Jetpack Compose UI Layer             |
                 | - HomeScreen (4 Dynamic Modes & Search)         |
                 | - MarkdownReaderScreen (Typography + Intercept) |
                 | - PracticeQuizScreen (Instant Feedback + Expl.) |
                 | - MockTestScreen (Timer + Palette + AutoSubmit) |
                 +-------------------------------------------------+
```

## ⚙️ Step-by-Step Setup Guide

### Step 1: Create Your GitHub CMS Repository
1. On GitHub, create a repository (e.g. `cdp-headless-cms`).
2. Clone it and push the following folders:
   - `study/`
   - `revision/`
   - `practice/`
   - `test/`
   - `.github/workflows/generate_manifest.yml`
   - `.github/scripts/generate_manifest.py`
3. In repository **Settings -> Actions -> General -> Workflow permissions**, enable **"Read and write permissions"** so GitHub Actions can commit the generated `manifest.json`.

### Step 2: Push New Content & Trigger Auto-Indexing
Whenever you push new notes (`.md`) or tests (`.json`):
```bash
git add study/ practice/ test/ revision/
git commit -m "feat: add new Piaget theories and mock test 2"
git push origin main
```
The GitHub Action will automatically:
1. Run `generate_manifest.py`.
2. Extract H1 headings, count questions, and compute test durations.
3. Automatically commit `manifest.json` back to your repo.

---

### Step 3: Configure the Android App

#### Option A: Build-Time Default Configuration
Open `app/build.gradle.kts` and update your default username and repo:
```kotlin
buildConfigField("String", "DEFAULT_GITHUB_OWNER", "\"YOUR_GITHUB_USERNAME\"")
buildConfigField("String", "DEFAULT_GITHUB_REPO", "\"cdp-headless-cms\"")
buildConfigField("String", "DEFAULT_GITHUB_BRANCH", "\"main\"")
```

#### Option B: Dynamic Runtime Configuration (In-App)
1. Open the app on your Android device.
2. Tap the **Settings (gear icon)** in the top right corner of the Home screen.
3. Enter your **GitHub Owner**, **Repository**, and **Branch**.
4. Tap **Apply & Sync**. The app immediately pulls and synchronizes with your repository without requiring any APK rebuild!

## 🌟 Key Architectural Features

### 1. Offline-First Caching Strategy
* **Room Database (`cdp_learning.db`)**: Every fetched markdown note, practice question set, mock test, and manifest index is persisted locally in `cached_content`.
* **OkHttp Stale Cache**: An offline network interceptor allows loading even without internet connectivity for up to 30 days.
* **Manual Offline Toggle**: Users can bookmark notes for persistent offline reading.
* **Offline Banner**: App informs the user when viewing cached content.

### 2. Markdown Reader & Internal Link Interception
* Seamless typography: H1-H4 headings, formatted markdown tables, quotes, strikethrough, and bullet points.
* **Link Interception**: When an author links another note using `[अगला अध्याय](piaget_cognitive_stages.md)`, Markwon intercepts the link and routes it internally to `MarkdownReaderScreen` rather than launching an external browser.
* **Font Size Adjuster**: Readers can adjust typography scale using an interactive slider.

### 3. Practice Mode
* Immediate visual evaluation:
  - **Correct answer chosen**: Button turns Emerald Green with checkmark.
  - **Incorrect answer chosen**: Selected button turns Red, and correct button highlights in Green.
* Animated expandable explanation card detailing the psychological rationale.

### 4. Full-Length Mock Test
* **Countdown Timer**: Automatically counts down and auto-submits when time reaches 0.
* **Question Palette**: Grid sheet indicating:
  - 🔵 **Attempted**
  - 🟡 **Marked for Review**
  - ⚪ **Unattempted**
* **Confirmation Dialog**: Prevents accidental submissions.
* **Score Report Card**: Displays total score, percentage, accuracy, time taken, and full question-by-question review with explanations.
